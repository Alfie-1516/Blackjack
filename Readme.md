
## Steps to Enhance `index.html` with Styles and Sections

### 1. Link to `index.css`
- In the `<head>` of `index.html`, add a link to `index.css`:
  - Place it **after** the reset and common stylesheet links.

### 2. Create the Hero Section
- Add a `<section>` with `id="hero"`.
- Style it with:
  - `width: 100%`
  - `height: 30vh`
- Include an `<h1>` with a tagline that contains the word **"Blackjack"**.

### 3. Create the "Why Us" Section
- Add a `<section>` with `id="whyUs"`.
- Style it with:
  - `width: 40%` (default).
  - `width: 100%` when the screen is **800px or smaller** (responsive design).
- Include a paragraph explaining **why** this is the best Blackjack app (containing the word "Why").

### 4. Create the Call to Action Section
- Add a `<section>` with `id="callToAction"`.
- Style it with:
  - `width: 40%` (default).
  - `width: 100%` when the screen is **800px or smaller** (responsive design).
- Include:
  - A paragraph containing the word **"Money"**.
  - A **button** labeled **"Start Playing"**.
