
### 1. Sketch a Wireframe
- Spend **2 minutes** sketching a basic wireframe to visualize the layout.

### 2. Fix the Header and Footer
- Set both the **header** and **footer** to have a `fixed` position for persistent visibility.

### 3. Style the Navigation
- Make the `<nav>` a **flex container** for flexible item arrangement.

### 4. Use Flexbox or Grid for Layout
- Utilize **Flexbox or Grid** to create a visually engaging and structured design.

### 5. Implement a Breakpoint
- Define a **breakpoint between 500px and 900px** for responsive adjustments.
- Apply styling in **common.css** to ensure consistency across pages.

### 6. Handle Responsive Display Elements
- Create an element with the class `.disappearing`:
  - **Only displayed above the breakpoint**.
- Create an element with the class `.mobileFeature`:
  - **Only displayed below the breakpoint**.

### 7. Redesign the About Page Content
- Use **CSS Grid** for the main content layout.
- Customize the grid structure to match a wireframe of your choice.
